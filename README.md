# Valheim — Forge Our World

A small, fan-made **Valheim co-op settings picker**. Share the site with a friend, have them pick their preferred world modifiers, and ask them to send their choices back.

**Website:** https://scraxemas.github.io/valheim-world-picker/

## What it does

- Seven difficulty presets: Easy, Standard, Hard, Hardcore, Casual, Hammer Mode, and Immersive.
- Five in-game-inspired sliders: combat, death penalty, resources, raids, portals.
- Six independent toggles: no build cost, no craft cost, player-based raids, passive creatures, no map, fire hazards.
- Optional Viking name.
- **Share My Choices** uses native sharing on supported devices or copies a text summary and results link.
- **Copy Text** copies a human-readable reply.
- **Copy Results Link** creates a URL with all selections encoded in the query string; no server, account, or database needed.
- Accessible controls, mobile layout, and no build step.

**Important:** Presets and individual modifiers are intentionally *independent preferences* in this poll. Selecting a preset does not automatically replace the other answers or change an actual Valheim world.

## Hosting

GitHub Pages deploys from `main` / `(root)`. The entire site lives in `index.html`. To edit the picker, update that file and GitHub Pages will publish the changes.

To use offline, save `index.html` and open it in a browser; link-sharing requires the hosted website.
